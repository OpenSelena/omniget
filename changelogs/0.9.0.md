🎉 **Update v0.9.0** ・ 29/08/2026

💬 **Chat is on.** OmniGet now has voice, video and screen sharing built in — no plugin, no browser, no second app. It ships turned on, already connected, and with a rule the big chat apps do not offer: your files live on the server for 30 minutes and then they are gone. Today's drop:

__💬 Chat, out of the box__
`01` 🚪 **No setup:** open Chat and you are already connected. Create an account and start talking — the server address only appears if you want to run your own.
`02` 🏠 **A place to land:** everyone who signs up joins the OmniGet community server, with rooms for help, bugs, general talk, and a channel for each of the ten languages OmniGet speaks.
`03` 🗂️ **Direct messages and servers, separated:** friends live on the home tab; a server shows only its own channels. Categories collapse, and unread channels stay visible when they do.
`04` 🎯 **Focus mode:** hide the app sidebar and let the chat fill the window. One button in the rail, and it remembers your choice.

__🖥️ Screen sharing that actually shows up__
`05` 👀 **Viewers see it now:** streams are discovered straight from the media layer instead of waiting on a status message that could go missing. When someone goes live, everyone in the channel sees LIVE and a Watch button.
`06` 🪞 **A preview of your own screen:** while you share, your tile shows what everyone else is seeing, so you never wonder whether you picked the right window.
`07` 🐧 **Linux support:** calls and screen sharing work on Linux, on both X11 and Wayland, through the desktop's own screen-sharing dialog. Hardware encoding (VAAPI, NVENC) is used when your machine has it, and the app says plainly when it falls back to software. Screen sharing needs a recent PipeWire, so the x86_64 build — kept on an older base so it still runs on older distros — ships with voice only for now, and tells you so; the arm64 build has both.
`08` ⛶ **Full screen works:** the pop-out stream window can go full screen, close properly, and closing it no longer prevents you from watching that person again.

__🎙️ Microphone__
`09` 🍎 **Fixed on macOS:** OmniGet now asks for microphone permission the way macOS requires. Before, the system silently handed the app an empty microphone — you looked connected and nobody could hear you.
`10` 🔇 **Silence is reported:** if your microphone delivers nothing at all, the mic test says so instead of showing a bar that never moves.

__🔒 Files that do not linger__
`11` ⏳ **Deleted after 30 minutes:** every file sent through chat is removed from the server automatically. Messages stay; attachments do not. Each one shows how long it has left, and afterwards reads "this file expired" instead of turning into a dead link.
`12` 🔐 **Encrypted on the server's disk:** uploads are encrypted at rest, so a stolen disk or a copied backup is unreadable. Direct messages were already end-to-end encrypted, and still are.
`13` 📊 **Honest about space:** if the server's disk fills up, everyone is warned while there is still room, and told plainly when a clean-up happens. No quotas, no fine print.
`14` 🚦 **Rate limits:** uploads are metered per account, so one person cannot fill the disk for everyone else.

__🔔 Notifications and polish__
`15` 🔕 **Notifications that arrive:** you now get notified for a channel you have open when the window is in the background — previously that case was silent.
`16` 🔴 **Unread badges on servers:** the server rail shows which servers have unread messages and how many mentions are waiting.
`17` 🎮 **Kinder to your games:** animations stop and the share preview pauses when OmniGet is not the window you are looking at, so a chat behind a game costs you as little as possible.
`18` 🇧🇷 **Portuguese screen-share text:** the entire sharing interface was translated — it was still English.
