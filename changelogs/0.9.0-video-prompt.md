# Nano Banana video prompt — OmniGet 0.9.0 "Chat is on"

Paste the block below into Nano Banana. It is written as one continuous brief
so the model keeps a single visual identity across shots. Keep the app's real
palette: near-black background (#0d0d10), off-white text, a single blue accent
(#3b82f6), red only for the LIVE badge and the expiry warning.

---

**PROMPT**

Create a 45-second product announcement video for **OmniGet 0.9.0 — "Chat is on"**.
OmniGet is a desktop app for downloading media that now has a built-in
Discord-style chat with voice, video and screen sharing. Dark, calm, precise —
closer to an Apple software reveal than to a gaming ad. No stock footage, no
people, no voice-over: only clean UI motion, on-screen type, and music.

**Look and feel**
- Dark interface on near-black (#0d0d10), off-white text (#f5f5f7), one blue
  accent (#3b82f6). Red (#ef4444) appears exactly twice: the LIVE badge and the
  file-expiry countdown.
- Typography: a modern geometric sans, generous spacing, large but never shouty.
- Motion: slow, weighted, physical. Elements settle rather than bounce. Cuts on
  the beat. No zoom bursts, no lens flares, no glitch effects.
- Music: a restrained electronic bed, soft pulse, builds once at 0:30 and
  resolves at the end. No sound effects over the UI.

**Shot list**

0:00–0:05 — Black. The OmniGet logo fades up centred, small. Beneath it, in
lighter weight: "Chat is on." Hold, then the logo slides up and out of frame.

0:05–0:12 — A dark chat window assembles itself: a narrow server rail on the
left, a channel list, a conversation. Messages appear one after another with a
gentle rise. Caption bottom-left: **"Voice, video and screen sharing — built
in."** Sub-caption in muted grey: "No plugin. No browser. No second app."

0:12–0:20 — Cut to a voice channel: circular avatars in a row, one of them
ringed in green as it "speaks", the ring breathing gently. A red **LIVE** badge
appears on one avatar, and a small preview thumbnail of a shared screen opens
underneath it. Caption: **"Share your screen — and see what they see."**

0:20–0:27 — Split screen. Left: the macOS system microphone-permission dialog
appearing over the app. Right: a level meter that was flat suddenly moving.
Caption: **"The microphone works again on Mac."**

0:27–0:34 — A Linux desktop (Wayland-style wallpaper, no distro logo). The
system screen-sharing picker appears; a monitor is chosen; the stream starts.
A small chip reads "VAAPI". Caption: **"Calls and screen sharing on Linux."**

0:34–0:42 — The emotional core, so give it room. A file card sits in a message.
Beside it a small countdown ticks down in red: "expires in 3 min… 2 min… 1 min".
The card then softly greys out and reads "This file expired". Caption, appearing
line by line:
  **"Every file you send is deleted from the server after 30 minutes."**
  **"Encrypted until then."**
  **"What the server no longer holds cannot leak."**

0:42–0:45 — Cut to black. Centred: the OmniGet logo, then in smaller type
"0.9.0 — available now" and the URL. Music resolves.

**Hard constraints**
- Never show a real person's name, face, avatar photo or message content. Use
  placeholder names like "alex", "sam", "noa" and generic text.
- Do not invent features: no AI assistant, no e2e-encrypted server channels, no
  mobile app. Everything shown must be one of the shots above.
- Do not imply the chat is anonymous or that messages are deleted — only files
  expire. Messages stay.
- Keep all UI text in English.
