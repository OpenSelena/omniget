How it works

Paste any supported link. OmniGet detects the source, picks the extractor, and manages the download.

  1. Paste linkVideo, course, post, magnet link, or .torrent file.
  2. Auto-detectRoutes to native extractors or yt-dlp automatically.
  3. Download & openSaved to your folder and ready in the built-in player.

Download settings and queue control

Configure output naming, quality presets, subtitles, connection limits, and browser cookies.

Command transparency: Every job records the exact command used, editable for reruns.
Resumable downloads: Interrupted transfers resume without starting over.
Adaptive connections: Up to 16 parallel fragments, with automatic backoff on rate limits.
Fast startup: Bundled runtime initializes in under a second.
Video: MP4, MKV, WebM Audio: MP3, M4A, Opus, FLAC, WAV Subtitles: SRT, VTT, ASS

What you download stays on your computer.

Everything runs locally. There is no account, no server of ours in the middle, and no telemetry about what you download.

Cookies and API keys live in your local profile, in the operating system's keyring.
Its only network calls go to the sites you asked for, to GitHub for updates, and to your AI provider.
The browser extension pairs over 127.0.0.1 with a per-install token, so it never leaves your machine.
Webviews run under a locked-down content security policy, and the file protocol refuses to open .ssh, .aws and .git.

What OmniGet refuses to do

  • It does not bypass DRM. Content marked with Widevine, FairPlay or PlayReady encryption is reported and skipped.
  • It does not break paywalls or share credentials. It downloads what your own logged-in session can already open.
  • It does not fingerprint you. Telemetry is opt-out and carries no URLs, device identifiers or IP addresses.

Free code signing on Windows is provided by SignPath.io, made possible by the SignPath Foundation.

Questions people ask first.

Is OmniGet free?

Yes. GPL-3.0, no paid tier, no ads, no account. This repository is an independent fork, maintained under the same licence.

Is it a yt-dlp GUI?

Partly. yt-dlp handles the long tail of sites; OmniGet bundles it, verifies it and updates it. Native extractors cover courses, Instagram, X, Pinterest, Bilibili, Telegram and torrents, and the queue adds resume and retry.

Can it download a Udemy or Hotmart course I bought?

Yes. The Courses plugin is built in and covers 36 platforms. Sign in, pick the sections, and download: lessons and attachments land in a folder per course and appear in Study. DRM-protected lectures are skipped and reported.

Can it download Instagram stories, close friends or highlights?

Yes, using your own session captured by the browser extension. Stories are downloaded without being marked as seen.

Can it back up a Pinterest board in original quality?

Yes, including videos, sections, secret boards with cookies, and incremental sync so you only fetch what is new.

Does it resume interrupted downloads?

Yes. Partial files are kept and continued, and rate limits trigger retries with backoff.

Does it need Python, Node or a terminal?

No. Download the app, open it, paste a link. The only terminal step is the one-time macOS Gatekeeper fix, which the documentation covers.

macOS says the app is damaged.

That is Gatekeeper reacting to an unsigned, un-notarised build. The two commands in the installation documentation clear it, and it happens once.

Can it transcribe a video to subtitles offline?

Yes. Tools, then Speech and subtitles, then Transcribe. It uses whisper.cpp locally and models download on demand.

Can an AI agent use OmniGet?

Two ways. The MCP server under Tools → AI exposes 37 tools to Claude Code, Claude Desktop, Cursor, VS Code, Goose and Codex. Separately, this repository ships a Claude Code plugin.
